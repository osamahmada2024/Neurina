# `.vendor/` Folder Documentation

## Overview

The `.vendor/` folder contains third-party source code that is **NOT available on PyPI** and is required for runtime functionality.

## What's in `.vendor/`

### `CodeFormer/` (Required)

- **Source**: GitHub repository https://github.com/sczhou/CodeFormer
- **Purpose**: Provides architecture modules (`basicsr/archs/`) for fine-grained face restoration
- **Why it's here**: CodeFormer's core architecture modules are not packaged in the pip release
- **Status**: ✅ Required - DO NOT DELETE

**Used by**: `src/services/face_restoration_service.py`

```python
# Dynamically loads from .vendor/CodeFormer/
codeformer_root = self.base_path / ".vendor" / "CodeFormer" / "basicsr" / "archs"
self._load_module_from_file("basicsr.archs.vqgan_arch", codeformer_root / "vqgan_arch.py")
self._load_module_from_file("basicsr.archs.codeformer_arch", codeformer_root / "codeformer_arch.py")
```

## What's NOT in `.vendor/`

### ~~`GFPGAN/`~~ (REMOVED)

- **Status**: ❌ Deleted - redundant
- **Why**: GFPGAN is available on PyPI (`gfpgan==1.3.8`) and installed via `requirements.txt`
- **Previous purpose**: Was a wrapper that loaded the pip package (unnecessary complexity)
- **Current approach**: Direct pip import in `face_restoration_service.py`

## `.gitignore` Rules

```gitignore
.vendor/GFPGAN/     # Don't commit GFPGAN (use pip instead)
# Note: .vendor/CodeFormer/ is still committed since it's essential
```

## What Gets Downloaded

These are downloaded automatically at runtime to `checkpoints/face_restoration/`:

- `GFPGANv1.4.pth` - GFPGAN model weights
- `codeformer.pth` - CodeFormer model weights

These are **NOT** in `.vendor/` - they're in `checkpoints/`.

## Maintenance

### If CodeFormer needs updating:

```bash
rm -rf .vendor/CodeFormer
git clone https://github.com/sczhou/CodeFormer.git .vendor/CodeFormer
```

### To verify structure:

```bash
ls -la .vendor/CodeFormer/basicsr/archs/
# Should show: codeformer_arch.py, vqgan_arch.py, ...
```

## Size Considerations

- `CodeFormer/` source: ~100-200 MB (includes training code, demos, not all needed at runtime)
- Model weights: Not stored in `.vendor/`, downloaded to `checkpoints/`

## Why Not Use Package Management for CodeFormer?

1. **Not on PyPI**: CodeFormer hasn't published to PyPI; only source available
2. **Submodule alternative**: Could use git submodule, but local copy is simpler for the use case
3. **Version stability**: Local copy guarantees specific version compatibility

## Troubleshooting

| Error | Solution |
|-------|----------|
| `FileNotFoundError: CodeFormer vendor archs not found` | Run `git clone https://github.com/sczhou/CodeFormer.git .vendor/CodeFormer` |
| `ModuleNotFoundError: basicsr.archs.codeformer_arch` | Check `.vendor/CodeFormer/basicsr/archs/` exists |
| `gfpgan is not installed` | Run `pip install -r requirements.txt` |
